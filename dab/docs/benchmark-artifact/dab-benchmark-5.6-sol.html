The finding: xhigh is a leveler

At high effort the harnesses are clearly separated — structured leads at 0.779, well ahead of dab0022 (0.722) and minimal (0.719). The scaffolding matters.

At xhigh that gap collapses: all three land in a dead heat around 0.77 (minimal 0.774, dab0022 0.769, structured 0.767 — within 0.007, far inside their run-to-run noise). xhigh lifts the weaker harnesses — minimal +0.055, dab0022 +0.047 — up to structured's level, while structured itself barely moves (−0.012).

Takeaway: the harness stops mattering at xhigh. Max reasoning erases the scaffolding advantage — so extra effort only rescues a weak harness, it doesn't raise the ceiling. Peak DAB (~0.78) is reachable either way; structured@high gets there for far fewer tokens.

Rows highlighted green = top stratified score. Token totals cover all 5 runs (270 query-trials). Spacedock·high carries the dab0022 semi-structured-rules README lever.

Benchmark. DAB scores an LLM solver on 54 analytics queries spanning 12 real datasets (Postgres / MongoDB / DuckDB). stratified pass@1 weights each dataset equally regardless of query count. Every configuration is a merge of 5 independent runs — 270 query-trials each, solved in 60 per-dataset codex sessions (12 datasets × 5 runs). Solver = codex runtime, model gpt-5.6-sol. All runs on razorback/harbor, uncapped (no agent timeout).

Token accounting. Totals are summed over all 5 runs; total = input + output (cached input is a subset of input). All figures are recovered from the codex session rollout logs' final total_token_usage. Direct-* harnesses run one codex session per dataset; the spacedock (dab0022) harness runs two — a first-officer thread that dispatches an ensign solver thread — and its total sums both.

Execution time. Mean wall-clock over the 60 dataset-sessions per config. Scopes differ slightly: direct-* is per-trial wall-clock (env-setup + agent + verifier); spacedock is codex agent task duration. Runs are uncapped, so means are true figures (the spacedock long tail is real, not truncated).

Notes. (1) The spacedock rows carry the dab0022 semi-structured-rules README on spacedock v0.24; the bare harnesses use no spacedock plugin. (2) At xhigh the three harnesses are a statistical three-way tie (~0.77, within 0.007 — far inside their ±0.03–0.05 run-to-run noise); read the whiskers, not the ordering. (3) One spacedock·xhigh draw scored 0.667 (its low outlier) on an isolated PATENTS answer-format flake — the solver emitted a list where the validator expects a string, scoring that dataset 0; it is a genuine draw, not an infrastructure error. (4) A 5-draw mean carries roughly ±0.03 of noise (minimal ±0.07). Reference lines: codex batch anchor 0.697, Opus-4.8 incumbent 0.654.
