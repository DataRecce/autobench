The finding: a stronger model flips which harness wins

On gpt-5.5, the crafted dab0022 README won — 0.743, ahead of structured (0.717) and minimal (0.710). The hand-written scaffolding earned its keep on the weaker model.

On gpt-5.6-sol the ranking flips. Lightly-structured leaps to 0.779 (+0.062) and takes the lead, while the README slips to 0.722 (−0.021) — from best harness to a dead tie with bare minimal (0.719). The stronger model already knows what the README was telling it; the rulebook just gets in the way.

Takeaway: the better the model, the less prompt scaffolding pays. As the slope shows, capability lifts the light harnesses and drags the prescriptive one down — they cross.

Benchmark. DAB scores an LLM solver on 54 analytics queries spanning 12 real datasets (Postgres / MongoDB / DuckDB). stratified pass@1 weights each dataset equally regardless of query count. Every configuration is a merge of 5 independent runs — 270 query-trials each, 60 per-dataset codex sessions. Solver = codex runtime; both models run at reasoning effort high. This page compares gpt-5.5 against gpt-5.6-sol on the identical three harnesses.

Token accounting. Totals are summed over all 5 runs; total = input + output (cached input is a subset of input). Direct-* token figures come from each run's result.json. On gpt-5.5, spacedock tokens were reconstructed from the codex session logs (~58M). On gpt-5.6-sol, the codex build updated for that model reports no usage for the multi-agent solver path (it logs only the first-officer thread), so its spacedock tokens show —.

Execution time. Mean wall-clock over the 60 dataset-sessions per config. Scopes differ slightly: direct-* is per-trial wall-clock (env-setup + agent + verifier); spacedock is codex agent task duration. The spacedock harness is the slowest on both models by ~2×.

Notes. (1) All configs run at reasoning effort high; the effort dimension is held fixed so the only variable is the model. (2) The spacedock harness carries the dab0022 semi-structured-rules README — v0.22 on gpt-5.5 (with one disclosed PATENTS fresh-draw substitution), v0.24 on gpt-5.6-sol; the plugin version doesn't affect the bare harnesses. (3) A 5-draw mean carries ~±0.03 of noise (direct-minimal ~±0.07) — read the whiskers, not small gaps between means; on a single draw minimal briefly looked like the gpt-5.6-sol winner before the distribution settled on structured. Reference lines: codex batch anchor 0.697, Opus-4.8 incumbent 0.654.
