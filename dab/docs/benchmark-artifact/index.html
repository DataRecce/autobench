What the four pages add up to

  • xhigh levels the field (gpt-5.6-sol). At high effort the harness matters (structured 0.779 ≫ dab0022 0.722 ≈ minimal 0.719); at xhigh all three converge to ~0.77. Max reasoning erases the scaffolding advantage.
  • Effort × README interaction inverts across models. xhigh hurts the rich dab0022 README on gpt-5.5 but helps it on gpt-5.6-sol — the substitute-levers behavior reverses as the model strengthens.
  • Hand-written scaffolding is obsolete on the stronger model. The crafted dab0022 README ties a bare minimal prompt on gpt-5.6-sol; a light structured frame is all that still earns its keep.
  • Peak DAB ≈ 0.78, reached cheaply. Structured @ high hits the ceiling for the fewest tokens; xhigh only rescues a weak harness, it doesn't raise the top.
Every configuration is a 5-run merge (270 query-trials each), solved in 60 per-dataset codex sessions. Solver = codex runtime; runs on razorback / harbor, uncapped. Source pages in dab/docs/benchmark-artifact/. Reference lines throughout: codex batch anchor 0.697, Opus-4.8 incumbent 0.654.
