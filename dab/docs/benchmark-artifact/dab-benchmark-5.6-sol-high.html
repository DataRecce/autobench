The finding: a stronger model doesn't need the README

On gpt-5.5, the crafted dab0022 README won (0.743 > structured 0.717 > minimal 0.710) — the hand-written scaffolding earned its keep. On gpt-5.6-sol the ranking flips: the lightly-structured harness leads at 0.779, while the prescriptive README (0.722) collapses to a dead tie with bare minimal (0.719, Δ 0.003). The README buys nothing the stronger model can't already do.

The gain is concentrated in structure: direct-structured jumps +0.062 over gpt-5.5, while minimal barely moves (+0.009) and the README actually slips (−0.021). A capable model rewards a light frame that stays out of its way — not a bare prompt, and not a rulebook it now fights.

A cautionary note on single draws. The first draw of each harness read minimal 0.770 as the winner. It wasn't — minimal's true 5-draw mean is 0.719 and it's the noisiest harness (0.595–0.783, sd 0.069). Structure only revealed itself as the real winner once all five draws were in. Rank harnesses on distributions, never on one run.

Row highlighted green = top stratified score. Token totals cover all 5 draws (270 query-trials). The spacedock row carries the dab0022 semi-structured-rules README (v0.24); its tokens are not metered (codex subscription). “bare” = a plain prompt harness with no lever.

Benchmark. DAB scores an LLM solver on 54 analytics queries spanning 12 real datasets (Postgres / MongoDB / DuckDB). stratified pass@1 weights each dataset equally regardless of query count. Every configuration is a merge of 5 independent runs — 270 query-trials each, solved in 60 per-dataset codex sessions (12 datasets × 5 runs). Solver = codex runtime, model gpt-5.6-sol, reasoning effort high.

Token accounting. Totals are summed over all 5 runs; total = input + output (cached input is a subset of input). Direct-* token figures come from each run's result.json; the spacedock (dab0022) solver runs on a codex subscription that does not meter tokens, so its usage shows —.

Execution time. Mean wall-clock over the 60 dataset-sessions per config. Scopes differ slightly: direct-* is per-trial wall-clock (env-setup + agent + verifier); spacedock is codex agent task duration. The spacedock harness's multi-agent structure makes it the slowest by ~2×.

Notes. (1) All three harnesses run at reasoning effort high; this page does not include the xhigh tier. (2) The spacedock row uses the dab0022 semi-structured-rules README on spacedock v0.24 (a separate v0.22 draw was excluded to keep the version clean); the bare harnesses use no spacedock plugin, so version is irrelevant to them. (3) “vs gpt-5.5” deltas compare against the same three harnesses at high effort on the prior model (structured 0.717, spacedock 0.743, minimal 0.710). (4) A 5-draw mean carries roughly ±0.03 of noise (minimal ±0.07) — read the whiskers, not small gaps between means. Reference lines: codex batch anchor 0.697, Opus-4.8 incumbent 0.654.
