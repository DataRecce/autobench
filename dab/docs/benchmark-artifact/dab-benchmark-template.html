The finding: effort and README are substitute levers

On the two bare harnesses, cranking reasoning effort to xhigh clearly helps — direct-minimal climbs 0.710 → 0.753 and direct-structured 0.717 → 0.763.

On spacedock v0.22 the direction inverts: the same xhigh jump hurts, 0.743 → 0.685. A prescriptive README already constrains the solver; extra reasoning unleashes second-guessing that fights those constraints — and it runs slow: 21 of 60 sessions (35%) hit the 1800s timeout, versus zero at high effort.

Takeaway: don't stack a rich harness with maximum effort. A lean harness at xhigh (direct-structured) beats a rich harness at xhigh — and edges the rich harness at high.

Rows highlighted green = top stratified score. Token totals cover all 5 runs (270 query-trials). Spacedock·high carries the dab0022 semi-structured-rules README lever.

Benchmark. DAB scores an LLM solver on 54 analytics queries spanning 12 real datasets (Postgres / MongoDB / DuckDB). stratified pass@1 weights each dataset equally regardless of query count. Every configuration is a CAIS-style merge of 5 independent runs — 270 query-trials each, solved in 60 per-dataset codex sessions (12 datasets × 5 runs). Solver = codex runtime, model gpt-5.5.

Token accounting. Totals are summed over all 5 runs; total = input + output (cached input is a subset of input). Direct-* token figures come from each run's result.json; spacedock·high is reconstructed from the codex session logs.

Execution time. Mean wall-clock over the 60 dataset-sessions per config. Scopes differ slightly: direct-* is per-trial wall-clock (env-setup + agent + verifier); spacedock·high is codex agent task duration; spacedock·xhigh is codex process wall time, capped at the 1800s timeout — so its mean is a lower bound (⚠ floor), not the true figure.

Notes. (1) Both spacedock rows are labelled spacedock v0.22. (2) spacedock·high additionally carries the dab0022 lever and includes one disclosed fresh-draw substitution on PATENTS run-005 — it is not a strict bare-harness baseline. (3) direct-structured·xhigh run-003 had 1 errored trial (scored on 49 queries). (4) spacedock·xhigh ran into the 1800s wall on 21 of 60 sessions (35%) — xhigh reasoning under the rich harness is slow — versus 0 timeouts at high effort; these incomplete sessions also mean its token usage was not captured (the newer codex log emits usage only on turn completion). Reference lines: codex batch anchor 0.697, Opus-4.8 incumbent 0.654.
