Reading this ledger

The config is frozen
Every run is the same pinned harness, model, effort, and board. This tracker never tunes for score — the sibling dab/hypotheses loop does that. A change here means the harness or the model moved, not the prompt.
Two trigger types
A spacedock release re-runs the pinned config on the new harness (model held at gpt-5.5). A model release swaps in the new model at the same effort. So consecutive rows rarely isolate one variable — the v0.25 row is the first that holds the model fixed against the v0.22 baseline.
The ±0.03 band
A five-draw stratified mean carries roughly ±0.03 of noise on this config. Deltas inside that band are not signal; the v0.25 corrected drop (−0.043) clears it.
Tokens & time
Counted from harbor session rollouts across the FO and ensign threads — not codex stdout, which undercounts ~5×. Session time is the mean per-dataset codex wall time.
